
# Night Vision

__Night Vision__ is a cyber threat intelligence (CTI) system for open source
software packages. It allows users to subscribe for alerts to new cyber threat
indicators on the open source software they use.

This repository is split between the Night Vision frontend (in `frontend/`),
which is the interactive web application through which users register packages
for tracking and receiving alerts to new cyber threats, and the backend (in
`backend/`), which is a REST API and analysis platform that runs analyses on
registered packages.
